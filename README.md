# 🎬 CORE France Project — Site vitrine

Site vitrine officiel du collectif de roleplay **CORE France Project**.

---

## 🇫🇷 Français

### 📍 Présentation

Ce site est la **vitrine officielle** de **CORE France Project** (*California Operational Roleplay Entity*), un collectif amateur de **jeu de rôle (RolePlay)** sur *Grand Theft Auto V*, joué via la plateforme **FiveM**. Il permet de présenter le collectif, ses membres, ses projets et ses réalisations, dans un cadre 100 % fictif et ludique, sans aucun but lucratif. On y trouve :

- 🧭 une page **Qui sommes-nous ?** présentant le collectif et les serveurs qui l'ont accueilli ;
- 👥 une liste des **membres** et de l'**équipe** ;
- 📁 les **projets** en cours et à venir ;
- 🏆 les **réalisations** passées du collectif ;
- 🖥️ les **serveurs partenaires** ;
- 🔐 un **espace membre** avec connexion via **Discord**, réservé aux membres du collectif.

ℹ️ L'ensemble des institutions, structures, forces de l'ordre, agences, organisations, grades, documents et personnages présentés sont **entièrement fictifs** et s'inscrivent dans un univers de roleplay — toute ressemblance avec des personnes, organismes ou institutions réels serait purement fortuite.

### 👥 Public visé

Ce site est destiné aux **membres du collectif CORE France Project**, ainsi qu'à tout **visiteur curieux** souhaitant découvrir le collectif, ses projets et ses réalisations.

### 🛠️ Technologies utilisées

- ⚛️ **Next.js 16** (App Router) & **React 19** — framework et rendu serveur/client
- 🔷 **TypeScript**
- 💨 **Tailwind CSS 4** — mise en forme
- 🗄️ **Prisma ORM** + **MySQL/MariaDB** — persistance des données
- 🔑 **jose** — authentification via Discord (OAuth / JWT)
- ✅ **Zod** — validation des données
- 🎯 **lucide-react** — bibliothèque d'icônes

## 🇬🇧 English

### 📍 Overview

This site is the **official showcase** of **CORE France Project** (*California Operational Roleplay Entity*), an amateur **roleplay (RP)** collective on *Grand Theft Auto V*, played via the **FiveM** platform. It presents the collective, its members, its projects, and its achievements, in a fully fictional and non-commercial context. It includes:

- 🧭 an **About us** page introducing the collective and the servers that hosted it;
- 👥 a list of **members** and the **team**;
- 📁 ongoing and upcoming **projects**;
- 🏆 the collective's past **achievements**;
- 🖥️ **partner servers**;
- 🔐 a **member area** with **Discord** login, reserved for collective members.

ℹ️ All institutions, structures, law enforcement agencies, organizations, ranks, documents, and characters presented are **entirely fictional** and are part of a roleplay universe — any resemblance to real people, organizations, or institutions would be purely coincidental.

### 👥 Target audience

This site is intended for **CORE France Project collective members**, as well as any **curious visitor** wanting to discover the collective, its projects, and its achievements.

### 🛠️ Tech stack

- ⚛️ **Next.js 16** (App Router) & **React 19** — framework and server/client rendering
- 🔷 **TypeScript**
- 💨 **Tailwind CSS 4** — styling
- 🗄️ **Prisma ORM** + **MySQL/MariaDB** — data persistence
- 🔑 **jose** — Discord-based authentication (OAuth / JWT)
- ✅ **Zod** — data validation
- 🎯 **lucide-react** — icon library
