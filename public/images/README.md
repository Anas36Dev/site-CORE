# Dossier images de CORE France Project

Dépose ici les visuels du site. Chaque sous-dossier a un rôle précis :

| Dossier | Contenu attendu | Utilisé par |
|---|---|---|
| `logo/` | Logo CORE (`core-logo.png`), favicon | Accueil, en-tête, onglet navigateur |
| `galerie/` | Screenshots d'ambiance du projet | Galerie de la page d'accueil |
| `projets/` | Logos de vos projets (police, gouvernement, illégaux…) | Pages « Nos projets » |
| `serveurs/` | Logos des serveurs qui vous ont accueillis | Page « Qui sommes-nous ? » |
| `membres/` | Avatars des membres | Fiches membres |
| `realisations/` | Affiches, logos, documents, dossiers | Page « Nos réalisations » |

## Conseils
- Formats recommandés : `.png` (logos, transparence) ou `.webp` / `.jpg` (screenshots).
- Nomme les fichiers simplement, sans espaces ni accents (ex. `fbi-dossier.png`, `serveur-anesya.png`).
- Le logo principal attendu par la page d'accueil : **`logo/core-logo.png`**.
