# Logos des structures / organisations

Dépose ici les logos des structures jouées dans les projets (légales **et** illégales) :
LSPD, BCSO, SASP, FBI, IRS, DOJ, USSS, Milicia de Cayo Perico, Cartel Madrazo, etc.

## Comment ça marche
Ces logos s'affichent automatiquement **à côté du nom de chaque structure** dans les pages
« Projets légaux » et « Projets illégaux » (petites pastilles sur les chips).

## Ce dont j'ai besoin de toi
1. Dépose les fichiers ici (`.png`, `.jpg`, `.gif`).
2. Donne-moi la correspondance **nom de la structure → fichier**
   (ex. « Federal Bureau of Investigation → fbi.png »),
   ou nomme les fichiers simplement (ex. `fbi.png`, `lspd.png`) et je fais l'association.

Je remplis ensuite la table `src/lib/structure-logos.ts` et c'est branché partout.
